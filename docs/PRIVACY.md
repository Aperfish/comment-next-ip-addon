# 数据处理说明

本扩展没有统计或遥测上报功能。使用者配置在线定位接口后，扩展会将待解析的评论 IP 发送给该接口；网络请求也会让服务商获知服务器出口 IP。服务商的数据处理方式由其政策决定。

分流使用本地 XDB。缓存位于进程内存，重启清空；不将完整 IP 作为前台属地字段返回。原评论插件和 Halo 本身对 IP 的存储不在本扩展控制范围内。

备用翻译默认关闭。启用后向所配置的服务商发送地名文本，不包含访客 IP、评论或用户身份。翻译结果有内存缓存，失败保留原名。管理员应自行确认服务商、配额、费用和数据处理条款。

API 密钥在插件设置中保存，不是前台配置。不要将配置导出、密钥、生产 IP 或未脱敏异常提交到 GitHub。

区县默认关闭并不意味着完整合规。维护者在 README 中的地域使用提醒也不等同于法律结论或自动地域限制。
