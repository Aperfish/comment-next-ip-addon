Use case: logo-brand. Generate one polished square app icon for a Halo blog plugin called Comment Next IP Location Addon. Main symbol merges a rounded speech bubble with a geographic location pin in a single coherent sculpted mark. Modern minimal premium 3D-soft style, rounded geometry, azure blue to turquoise gradient symbol on a very pale cool white background, delicate shadow, excellent contrast at 32px, generous safe margin 14%, front facing, clean centered composition, no border, no words, no letters, no numbers, no watermark, no flags, no maps or country outlines. A single original icon only, not a contact sheet or mockup. Square 1:1 image. Intended as the actual plugin logo in Halo console and GitHub README.
